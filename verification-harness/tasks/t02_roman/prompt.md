Write a Python function `roman_to_int(s: str) -> int`.

`s` is a valid Roman numeral between 1 and 3999, written in uppercase with the standard symbols
`I=1, V=5, X=10, L=50, C=100, D=500, M=1000` and the standard subtractive pairs
(`IV, IX, XL, XC, CD, CM`). Return its integer value.

Examples:

- `roman_to_int("III")` → `3`
- `roman_to_int("MCMXCIV")` → `1994`
